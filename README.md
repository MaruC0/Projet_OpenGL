# Projet_OpenGL

Nous avons réalisé un simple projet de jardin géant.

Nous avons une caméra qu'il est possible de déplacer horizontalement avec ZQSD ainsi que la possibilité de zoomer.
Notre jardin comporte un sol avec une texture, une skybox avec un soleil ainsi qu'une illumination de phong adaptée à des textures.
Nous avons également des herbes, modélisées à l'aide de Assimp. Malheureusement, nous n'avons pas réussi à intégrer la texture du modèle, qui était assez mal implémentée par le concepteur du modèle. Nous avons donc remplacé cela par un simple shader couleur qui fait apparaître l'herbe en vert. 
Nous avons aussi un personnage qui fait coucou au centre du projet.
