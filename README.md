# Projet_OpenGL

Nous avons réalisé un simple projet de jardin géant.

Nous avons une caméra qu'il est possible de déplacer horizontalement avec ZQSD ainsi que la possibilité de zoomer.  
Notre jardin comporte un sol avec une texture, une skybox qui se charge en dernière pour éviter les parties qui sont cachées, un soleil ainsi qu'une illumination de phong adaptée à des textures.  
Nous avons également des herbes, modélisées à l'aide d’Assimp, générées à peu près aléatoirement pour remplir la zone.  
Les herbes ont une texture et sont soumises à l’illumination de phong.  
Nous avons également un avion ajouté via Assimp, il est d’une seule couleur et possède aussi l’illumination de phong.  
Nous avons aussi un personnage qui fait coucou au centre du projet.  
Nous avons codé la possibilité de se mettre en vue à la 3ème personne, centré sur le personnage qui fait coucou, mais nous l’avons commentée pour faute de finition.  
Le code final se trouve dans la branche alexSol.
